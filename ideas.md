# VectorForge Editor — Visual Direction

## Three stylistic approaches

### Theme Name: Precision Instrument
Very pale mineral workspace, ink-black chrome, and a single electric cobalt control color. It should feel like a serious drafting instrument: quiet, measured, and built for exact work.
**Probability:** 0.07

### Theme Name: Studio Paper
Warm paper surfaces, graphite controls, red registration marks, and editorial typography evoke a print studio with tactile, analog restraint.
**Probability:** 0.03

### Theme Name: Night Signal
Deep charcoal canvas chrome with acid-lime selection states and sharp cyan guides creates a cinematic, high-contrast control room for rapid visual making.
**Probability:** 0.09

## Chosen approach: Precision Instrument

### Design Movement
Swiss International Typographic Style translated into a modern creative-tool interface: restrained geometry, asymmetrical rhythm, strict alignment, and information that earns its space.

### Core Principles
1. **Quiet chrome, loud state:** the workspace remains low-contrast and calm; selection, active tools, and warnings are unmistakable.
2. **Measured density:** compact controls sit beside generous canvas breathing room, like an instrument panel surrounding a drafting table.
3. **Visible precision:** coordinates, dimensions, zoom, and layer state are always legible without becoming spreadsheet-like.
4. **Functional contrast:** cobalt is reserved for action and focus; warm signal red appears only for destructive or registration moments.

### Color Philosophy
The base is mineral white and cool graphite, a neutral field that lets user artwork remain the visual subject. Ink-black type gives the interface authority, while electric cobalt (#3157D5) acts as an ownable, high-salience focus color for active tools, handles, and primary actions. A small vermillion accent (#E45B46) marks attention and irreversible actions without turning the whole product into a warning system.

### Layout Paradigm
A fixed desktop instrument frame: a slim menu rail on top, a narrow tool strip on the left, a broad canvas well in the middle, and a contextual inspector stack on the right. The layout is intentionally asymmetric; the canvas starts off-center to make the inspector feel like a deliberate counterweight rather than a generic dashboard column.

### Signature Elements
- Cobalt “registration ticks” and crosshair details on active controls.
- Thin ruled separators with tiny uppercase section labels.
- A floating ivory artboard on a cool gray drafting field, with a soft offset shadow rather than a heavy card border.

### Interaction Philosophy
Interactions should feel like physical instrument adjustments: direct, reversible, and readable. Tool buttons latch with a visible cobalt indicator; selection handles are crisp; inspector fields respond immediately and preserve keyboard accessibility. Nonessential interface motion is short and directional, while keyboard shortcuts remain instant.

### Animation
Use 140–200ms ease-out transitions for tool activation, panels, and hover states. Animate only opacity and transform. Use a 30ms stagger for layer rows when the document loads. Avoid decorative loops; instead, use a single subtle “calibration” pulse on the active canvas status when a tool changes. Respect reduced-motion preferences.

### Typography System
Use **IBM Plex Sans** for interface copy and **Space Mono** for coordinates, dimensions, and metadata. Headlines use IBM Plex Sans at 700 with tight tracking. Section labels use Space Mono at 10–11px, uppercase, with 0.12em tracking. Numeric inputs and status readouts always use Space Mono to reinforce instrument precision.

### Brand Essence
**VectorForge is a precise, approachable vector workspace for designers who want professional control without heavyweight ceremony.**
Personality: exacting, calm, inventive.

### Brand Voice
Headlines are concise and declarative. CTAs are verbs with a sense of craft rather than marketing hype. Microcopy explains state, not process theater.

Example lines:
- “Make the geometry carry the idea.”
- “Snap is on. Your next move is measured.”

### Wordmark & Logo
The mark is a geometric cobalt forge-chevron: two offset angle brackets facing inward around a small square registration point. It suggests both vector nodes and a tool being calibrated. The wordmark is set separately in a custom wide-tracked treatment; the icon must remain recognizable without the name.

### Signature Brand Color
**Forge Cobalt — #3157D5.** It is cool, decisive, and legible at small sizes; it belongs to VectorForge as the visual signal for control, not decoration.
